Run the Demo Locally

CareerMappingGenomics is a deep learning system that requires Python and PyTorch. The fastest way to try it is with Docker — no Python installation needed.

# One-command Docker demo (~30 seconds)
git clone https://github.com/abdallaheldaly/CareerMappingGenomics.git
cd CareerMappingGenomics
docker build -t careermapping:v1 .
docker run --rm -v $(pwd)/output:/app/output \
  careermapping:v1 python main.py --quick

Or launch the interactive REST API and explore it in your browser:

# Start the API server
docker run --rm -p 8000:8000 careermapping:v1 python src/api/app.py
# → Open: http://localhost:8000/docs

For the interactive visual explorer (no installation needed), open the .jsx files in Claude.ai as artifacts:

  • CareerMappingGenomics_UI.jsx — full interactive data input & career results
  • CareerMappingGenomics_SystemDesign.jsx — system architecture explorer
